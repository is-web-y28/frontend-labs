# Лабораторные работы осеннего семестра

Первые три лабораторные работы посвящены разработке нескольких страниц по заданному макету, четвёртая лабораторная работа - самостоятельное приложение с использованием фреймворка, оставшиеся три лабораторные работы - это этапы проекта, тему которого вы определяете самостоятельно и согласовываете с преподавателем практики заранее.
