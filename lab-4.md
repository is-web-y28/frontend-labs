# Лабораторная работа 4. Приложение на React

## Задача
Сделать SPA на React с данными из API: 
- Список с поиском и пагинацией
- Детальная страница — есть разные смысловые блоки на странице
- Cоздание, редактирование и удаление элементов
- Фильтрация.

Проект в том же репозитории в **отдельной** ветке (например, `lab-4`)

## Источник данных

**Общие требование**: наличие пагинации, изображений, даты создания объектов, богатая доменная модель (существует больше одной сущности)

На выбор:

- [Star Wars API](https://www.swapi.tech/)
- [Mock Products API](https://dummyjson.com/docs/products)
- [Pokemon API](https://pokeapi.co/)
- [Anime API](https://docs.api.jikan.moe/)
- своё моковое API на [MSW](https://mswjs.io). Если создаете моки, то должен быть полноценный CRUD

## Стек технологий

**База:** React 19, Vite, Typescript

**Стилизация [на выбор]**: CSS Modules, Tailwind, styled-components, emotion, SCSS и т.п. **При выборе подхода надо суметь объяснить выбор: назвать плюсы и минусы**

Интерфейс собирается через **библиотеку компонентов [тоже на выбор]**:

- [Mantine](https://mantine.dev/)
- [Material UI](https://mui.com/)
- [Chakra UI](https://chakra-ui.com/)
- [Hero UI](https://heroui.com/)

Глобальной разницы между ними нет, берите что понравилось больше. Можно брать любой другой ui-kit — главное, чтобы в нем было много разных компонентов.

Запросы можно выполнять через сторонние библиотеки: [axios](https://github.com/axios/axios) / [ky](https://github.com/sindresorhus/ky). 
Можно и через нативный `fetch`, но это менее удобно.

## Требования к реализации

- **Только** функциональные компоненты и хуки;
- Маршрутизация через [react-router](https://reactrouter.com/home)
  - Должна быть страница 404
- Фильтры (в т.ч. пагинация) хранятся в URL: перезагрузка и кнопка «Назад» сохраняют состояние
- Поиск с `debounce`: запрос не уходит на каждое нажатие клавиши
- Запросы вынесены в отдельный модуль, компоненты не вызывают fetch / библиотеку напрямую;
- У каждого списка есть четыре состояния:
  1. Загрузка. Нужен компонент `skeleton`
  2. Ошибка с кнопкой повтора
  3. Пустой результат
  4. Отображение самих данных
- Удаление с подтверждением в модальном окне
- После создания, правки и удаления интерфейс обновляется без перезагрузки страницы, результат операции показывается уведомлением — можно
  воспользоваться библиотекой [Sonner](https://github.com/emilkowalski/sonner), либо решением из вашего ui-kit
- **минимум один собственный хук**;
- `key` в списках — id сущности, не индекс;
- отфильтрованные и вычисляемые данные не хранятся в отдельном `state`, а считаются при рендере;
- **интерфейс адаптивный**
